مشروع سنتات Android — الإصدار 1.3.9

1) فك ضغط ملف المشروع.
2) أنشئ Repository جديد في GitHub.
3) ارفع جميع محتويات مجلد المشروع إلى المستودع (بما فيها مجلد .github).
4) ادخل Actions > Build SNTAT Android APK > Run workflow.
5) بعد اكتمال البناء نزّل Artifact: SNTAT-v1.3.9-debug-APK.
6) فك ضغط الملف الناتج وستجد app-debug.apk.

ملاحظة: هذا APK تجريبي؛ لتحديث تطبيق قديم تحتاج نفس اسم حزمة التطبيق القديم وشهادة التوقيع الأصلية.
