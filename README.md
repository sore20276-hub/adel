# سنتات | SNTAT — Android 1.3.9

مشروع أندرويد أصلي (Java + Android WebView) قابل للفتح والتعديل في **Android Studio أو VS Code**. الأيقونة الأصلية مضافة كما أُرسلت.

## المزايا

- الأيقونة: حرف S أبيض حليبي وذهبي/برتقالي، واسم التطبيق على الهاتف «سنتات».
- شاشة ترحيب **4 ثوانٍ**: صورة التطبيق + رسالة عربية + أحرف خضراء تتساقط من الأعلى.
- مؤثر صوتي WAV محلي؛ يحاول أيضاً نطق «أهلاً بكم في سنتات» عبر محرك النطق العربي المثبت على الهاتف إن كان متوفراً. المؤثر الصوتي مضمون وجوده دون إنترنت، أما النطق فيعتمد على بيانات الهاتف.
- يفتح `https://sntat.shop/auth?mode=signin` **داخل التطبيق** بدلاً من تشغيل متصفح خارجي.
- JavaScript، وDOM Storage، وملفات تعريف الارتباط Cookies، والتخزين المؤقت اللازم للمنصة مفعلون. لم نكتب آلية لجمع أو حفظ كلمات المرور في ملفات التطبيق.
- حفظ آخر صفحة عادية آمنة داخل `sntat.shop` والرجوع إليها عند فتح التطبيق؛ يعيد خادم الموقع المستخدم إلى صفحة الدخول إن كانت الجلسة منتهية.
- رسائل `alert` و`confirm` و`prompt` الخاصة بـJavaScript تظهر بحوارات تحمل اسم سنتات. صفحة عدم الاتصال وإعادة المحاولة داخلية.
- روابط HTTPs وفتح النوافذ الجديدة تُعالَج في متصفح التطبيق ما أمكن، مع منع روابط HTTP غير الآمنة.
- اختيار الملفات يتطلب منتقي الملفات الذي يقدمه نظام أندرويد؛ الموقع أو صلاحية الكاميرا/الموقع يمكن أن تتطلب موافقة أندرويد الرسمية لأسباب أمنية، ولا يمكن إلغاؤها.
- تنزيل الملفات اختياري، إلى مجلد التنزيلات الخاص بالتطبيق بإدارة Android DownloadManager. قد يظهر إشعار نظام عادي أثناء التنزيل.

## رفع الملفات إلى GitHub وبناء APK آلياً

1. أنشئ مستودع GitHub جديداً (مثال `sntat-android`).
2. فك ضغط ملف ZIP، ثم ارفع **محتويات** مجلد `SNTAT-Android-v1.3.9` إلى جذر المستودع. تأكد أن `.github/workflows/build-apk.yml` موجود في جذر المشروع (قد تحتاج إظهار الملفات المخفية).
3. افتح **Actions → Build SNTAT Android APK → Run workflow** (أو ادفع commit إلى فرع `main`). إذا كانت Actions غير مفعلة اسمح بتشغيلها في إعدادات المستودع.
4. بعد نجاح التشغيل، افتح آخر Workflow واختر **Artifacts → SNTAT-v1.3.9-debug-APK**.
5. حمّل ZIP الخاص بالـArtifact واستخرج `app-debug.apk` وثبّته على أندرويد. هذا بناء **تجريبي Debug** صالح للتجربة، وليس نسخة نشر نهائية موقعة بمفتاحك.

> GitHub Actions يجلب Gradle 8.9 تلقائياً. هذا المشروع لا يضم ملف `gradle-wrapper.jar` الثنائي، لذا يستعمل CI نسخة Gradle المثبتة بواسطة `setup-gradle`. إذا رغبت ببناء محلي مع `gradlew.bat`، افتح المشروع في Android Studio وولّد Gradle Wrapper عبر `gradle wrapper --gradle-version 8.9` بعد تثبيت Gradle، أو استعمل Gradle مثبتاً مباشرة.

## Android Studio / VS Code

- JDK: 17؛ Android SDK: 35؛ Gradle: 8.9؛ Android Gradle Plugin: 8.7.3.
- افتح **مجلد المشروع**. في Android Studio اضبط Gradle على إصدار 8.9 المتوفر لديك إذا طُلب ذلك، وانتظر المزامنة، ثم `Build > Build APK(s)`.
- في VS Code يمكنك تعديل الملفات، لكن بناء APK يتطلب أدوات Android SDK وGradle (أو Actions على GitHub).

## مهم: تحديث تطبيق قديم بدلاً من تثبيت تطبيق جديد

للتحديث فوق تطبيق موجود مسبقاً يجب أن يطابق **applicationId** رقم حزمة التطبيق القديم وأن يكون APK الجديد موقعاً **بنفس شهادة/مفتاح التوقيع الأصلي**، إضافة إلى `versionCode` أعلى من القديم. **لا تغيّر package عشوائياً**. نسخة GitHub Debug تستخدم مفتاح توقيع تجريبياً، وقد تختلف شهادته بين مرات البناء على خوادم مختلفة؛ لذلك لا تصلح كتحديث مستقر للمستخدمين. إذا كان لديك مشروع الإصدار القديم وملف مفتاح التوقيع، يجب تهيئتهما قبل توزيع تحديث 1.3.9.

## ملاحظات فنية واقعية

1. استمرار جلسة الدخول بعد إغلاق التطبيق يعتمد أيضاً على **نوع وتاريخ انتهاء Cookies/رموز الجلسة الصادرة من الموقع**. هذا المشروع يمنع المسح المتعمد ويسمح بحفظ التخزين المحلي، لكنه لا يستطيع إجبار خادم `sntat.shop` على الاحتفاظ بجلسة منتهية.
2. تسجيل الدخول بحساب Google داخل WebView قد يُرفض وفق قواعد Google OAuth. الحل الرسمي عند الحاجة هو إدخال OAuth عبر متصفح موثوق + `redirect`/deep link من الخادم أو SDK أصلي، ويتطلب إعدادات من مالك الموقع. لا يُنصح بالتحايل على شروط Google.
3. حوارات أندرويد الرسمية للصلاحيات وانتقاء الملفات لا يجوز استبدالها بصلاحيات صامتة؛ رسائل الموقع العادية وأخطاء الاتصال توضع داخل واجهة التطبيق.
4. هذا مشروع **مصدر كامل** وليس APK جاهزاً؛ يجب بناؤه على Android Studio أو GitHub Actions.
5. لا تضع كلمات المرور، API secrets، أو مفاتيح توقيع APK داخل المستودع العام.
